cron

import tinox.core.cron;

Cron-Expression Parser und Job-Scheduler für zeitgesteuerte Aufgaben. Unterstützt Standard-Cron-Syntax (Minute Stunde Tag Monat Wochentag).

Klassen

Cron

MethodeSignaturBeschreibung
parsefn parse(expr: String) -> CronExprCron-Ausdruck parsen (5 Felder)
nextRunfn nextRun(expr: CronExpr) -> Int64Nächste Ausführungszeit in ms
matchesfn matches(expr: CronExpr, timestamp: Int64) -> BoolPrüft ob Zeitstempel zum Ausdruck passt

CronExpr

Felder: minute, hour, dayOfMonth, month, dayOfWeek (alle String)

CronScheduler

MethodeSignaturBeschreibung
newfn new() -> CronSchedulerNeuen Scheduler erstellen
addJobfn addJob(scheduler, expr: String, callback: fnc() -> Unit) -> UnitJob mit Cron-Ausdruck registrieren
startfn start(scheduler) -> UnitScheduler aktivieren
stopfn stop(scheduler) -> UnitScheduler deaktivieren
tickfn tick(scheduler) -> UnitEinen Tick verarbeiten, fällige Jobs ausführen

Beispiel

import tinox.core.cron;

fn main() -> Int64
{
    let scheduler: CronScheduler = CronScheduler::new();

    // Jeden Monat um Mitternacht
    CronScheduler::addJob(scheduler, "0 0 1 * *", fnc() -> Unit
    {
        println("Monatlicher Report gestartet");
    });

    // Jede Minute
    CronScheduler::addJob(scheduler, "* * * * *", fnc() -> Unit
    {
        println("Heartbeat");
    });

    CronScheduler::start(scheduler);
    CronScheduler::tick(scheduler);
    return 0;
}
