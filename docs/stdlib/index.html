Standardbibliothek

Vollständige Referenz der Tinox-Standardbibliothek — alle Module auf einen Blick.

Datenstrukturen & Algorithmen

array
import tinox.core.array;
Utility-Klasse für Operationen auf Integer-Arrays: Suchen, Transformieren, Sortieren und Generieren von Ranges.
collections
import tinox.core.collections;
Datenstruktur-Implementierungen: Stack (LIFO), Queue (FIFO) und Pair. Factory-Klasse Collections für einfache Erzeugung.
heap
import tinox.core.heap;
Heap-Datenstrukturen: generischer Heap mit benutzerdefiniertem Comparator, MinHeap und MaxHeap.
iter
import tinox.core.iter;
Iterator-Utilities: range, repeat, cycle, enumerate, zip sowie map/filter/reduce für Listen.
queue
import tinox.core.queue;
Priority Queue mit Insertion-Sort und zirkulärer Buffer-Implementierung.
set
import tinox.core.set;
Generische Menge (Set) ohne Duplikate: add, remove, contains und Mengenoperationen (union, intersection, difference).
sort
import tinox.core.sort;
Sortieralgorithmen für Integer-Listen: QuickSort, MergeSort und InsertionSort.
graph
import tinox.core.graph;
Generische Graphdatenstruktur mit gewichteten Kanten, BFS, DFS und Dijkstra-Algorithmus.
trie
import tinox.core.trie;
Trie-Datenstruktur für präfixbasierte Stringsuche und Autocomplete-Funktionalität.

Mathematik & Zahlen

math
import tinox.math;
Integer-Mathematik: Konstanten (π, e, τ), abs, min, max, pow, factorial und LCG-Pseudozufallsgenerator.
mathf
import tinox.mathf;
Float-Mathematik: sqrt, pow, floor, ceil, round, clamp, lerp und trigonometrische Funktionen.
mathx
import tinox.mathx;
Erweiterte Mathematik: GCD, LCM, Primzahlen, Fibonacci, Kombinatorik, modulare Potenz und Ziffernoperationen.
complex
import tinox.complex;
Komplexe Zahlen mit Arithmetik, polaren Koordinaten, trigonometrischen und transzendenten Funktionen.
decimal
import tinox.decimal;
Dezimalarithmetik mit beliebiger Präzision für finanzielle Berechnungen. Vermeidet Gleitkomma-Rundungsfehler.
random
import tinox.random;
Zufallszahlengenerator: Integer, Float, Bool, Listenauswahl, Shuffle, Sample und zufällige Strings.

Strings & Kodierung

string
import tinox.string;
String-Hilfsfunktionen: Inspektion, Transformation, Aufteilen, Zusammenführen und Typkonvertierung.
fmt
import tinox.fmt;
Printf-artige Formatierung mit Platzhaltern: %s (String), %d (Integer), %f (Float), %x (Hex), %b (Binär).
format
import tinox.format;
String-Formatierung mit Padding, Binär- und Hex-Konvertierung sowie rechtsbündigem Integer-Format.
encoding
import tinox.encoding;
Text-Encoding-Utilities: Zeichencode-Konvertierung, UTF-8-Byte-Konvertierung und HTML-Entity-Kodierung/-Dekodierung.
base64
import tinox.base64;
Base64-Kodierung und -Dekodierung für Strings und Byte-Arrays.
hex
import tinox.hex;
Hexadezimale Kodierung und Dekodierung von Binärdaten sowie Hex-Dump-Ausgabe.
regex
import tinox.regex;
Reguläre Ausdrücke: Matching, Suche, Ersetzung und Splitting via Extern-API.
uri
import tinox.uri;
URI-Kodierung und -Dekodierung sowie strukturiertes Parsing von URLs in Scheme, Host, Pfad, Query und Fragment.

Datenaustauschformate

json
import tinox.json;
JSON-Parsing und -Serialisierung mit Typprüfung und Wert-Extraktion via JsonValue.
csv
import tinox.csv;
CSV-Parser und Serialisierer. Unterstützt gequotete Felder mit Kommas und eingebetteten Anführungszeichen.
xml
import tinox.xml;
XML-Parsing und -Serialisierung mit Knotennavigation, Attributzugriff und XPath-Queries.
yaml
import tinox.yaml;
YAML-Parsing und -Serialisierung mit Typ-Unterstützung für Maps, Listen und Skalare.
toml
import tinox.toml;
TOML-Konfigurationsdateien parsen und serialisieren mit vollständiger Typunterstützung.
ini
import tinox.ini;
Parser und Serialisierer für INI-Konfigurationsdateien mit Sections und Key-Value-Paaren.

Netzwerk & HTTP

http
import tinox.http;
HTTP-Client für GET, POST, PUT, DELETE und PATCH-Anfragen mit Header-Verwaltung.
http_server
import tinox.http_server;
Vollständiger HTTP/1.1-Server mit Routing, Middleware-Support, Pfad-Parametern und Query-String-Parsing.
http2_server
import tinox.core.http2_server;
Vollständiger HTTP/2-Server (RFC 7540) mit binärem Framing, HPACK-Header-Kompression und Stream-Multiplexing. Gleiche API wie http_server.
hpack
import tinox.core.hpack;
HPACK-Header-Kompression für HTTP/2 (RFC 7541): statische Tabelle (61 Einträge), dynamische Tabelle, Integer- und String-Kodierung.
rest
import tinox.rest;
REST-Client mit fluenter API: GET, POST, PUT, PATCH, DELETE mit Header-Verwaltung, Bearer/Basic-Auth und URL-Builder.
rest_framework
import tinox.rest_framework;
Annotations-basiertes REST-Framework für deklaratives API-Routing mit @GET, @POST, @PUT, @DELETE, Middleware und Dependency-Injection.
socket
import tinox.socket;
TCP- und UDP-Socket-Abstraktion mit connect, bind, listen, accept, send und receive.
jwt
import tinox.jwt;
JWT-Token Erstellung und Verifikation mit HMAC-SHA256-Signatur und Ablaufprüfung.

Kryptografie & Sicherheit

crypto
import tinox.crypto;
Kryptografische Funktionen: Hashing (MD5, SHA-256), HMAC, AES-Verschlüsselung und Schlüsselableitung (PBKDF2).
hash
import tinox.hash;
Hash-Funktionen für Strings und Integer: DJB2-Algorithmus, Integer-Hash und Hash-Kombination.
validation
import tinox.validation;
Eingabe-Validierung: E-Mail, URL, numerisch, alpha, alphanumerisch, Telefon, Längen- und Wertebereichs-Prüfungen.
uuid
import tinox.uuid;
UUID-Generierung und -Validierung mit String-Parsing.

System & I/O

io
import tinox.io;
Ein-/Ausgabe-Utilities: Buffer für String-Konkatenation, File-Handle und Pfad-Manipulation.
fs
import tinox.fs;
Dateisystem-Operationen: Lesen, Schreiben, Kopieren, Verschieben, Löschen von Dateien und Verzeichnissen.
env
import tinox.env;
Zugriff auf Umgebungsvariablen und das aktuelle Arbeitsverzeichnis des Prozesses.
process
import tinox.process;
Prozess-Utilities: Exit-Code, Sleep, PID, Kommandozeilenargumente und Umgebungsvariablen.
debug
import tinox.debug;
Debug-Utilities: Assertions, Panic, Stack-Trace, Typ-Inspektion und Garbage-Collector-Steuerung.
zip
import tinox.zip;
ZIP-Archiv-Handling: erstellen, öffnen, auflisten, extrahieren, hinzufügen und entfernen von Dateien.

Nebenläufigkeit & Zeitsteuerung

semaphore
import tinox.semaphore;
Synchronisationsprimitiven: Semaphore, Mutex und RWLock (Reader-Writer-Lock).
pool
import tinox.pool;
Generischer Objekt-Pool für Ressourcen-Wiederverwendung mit acquire/release-Semantik.
ratelimit
import tinox.ratelimit;
Rate-Limiting: Sliding-Window RateLimiter und Token-Bucket-Algorithmus für Anfragen-Drosselung.
cron
import tinox.cron;
Cron-Expression Parser und Job-Scheduler für zeitgesteuerte Aufgaben. Unterstützt Standard-Cron-Syntax.
events
import tinox.events;
Event-Emitter für das Publish-Subscribe-Pattern. Registriere Handler für benannte Events und emittiere Daten an alle Listener.
time
import tinox.time;
Zeit-Utilities: Systemzeit, Sleep, Duration (Sekunden/Minuten/Stunden), Timer und Stopwatch.
cache
import tinox.cache;
Generischer LRU-Cache mit konfigurierbarer Maximalgröße. Älteste Einträge werden automatisch verdrängt, wenn der Cache voll ist.

Typen & Fehlerbehandlung

import tinox.option;
Option-Typ für nullable Werte: some/none Varianten mit sicherem Unwrapping und Transformationen.
result
import tinox.result;
Result-Typ für Fehlerbehandlung: ok/err Varianten mit sicherem Unwrapping und Transformationen.

Logging & Templates

logger
import tinox.logger;
Konfigurierbares Logging mit Level-Filter (Debug, Info, Warn, Error) und Timestamp-Ausgabe.
tpl
import tinox.tpl;
Template-Engine mit {{variable}}-Substitution, Schleifen-Rendering und vorkompilierten Templates.

Grafik & Low-Level
