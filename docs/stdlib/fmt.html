fmt

import tinox.core.fmt;

Printf-artige Formatierung mit Platzhaltern: %s (String), %d (Integer), %f (Float), %x (Hex), %b (Binär).

Klassen

Fmt

MethodeSignaturBeschreibung
sprintffn sprintf(format: String, args: List<String>) -> StringFormatstring auswerten, String zurückgeben
printffn printf(format: String, args: List<String>) -> UnitFormatierter Text ausgeben (ohne Newline)
printlnffn printlnf(format: String, args: List<String>) -> UnitFormatierter Text mit Newline ausgeben

Format-Spezifizierer

SpezifiziererBedeutung
%sString
%dInteger (Dezimal)
%fFloat
%xHexadezimal (lowercase)
%bBinär
%%Literal %

Beispiel

import tinox.core.fmt;

fn main() -> Int64
{
    // Formatierter String
    let msg: String = Fmt::sprintf(
        "Hallo %s! Du bist %d Jahre alt.",
        ["Alice", "30"]
    );
    println(msg); // "Hallo Alice! Du bist 30 Jahre alt."

    // Hex-Ausgabe
    Fmt::printlnf("Wert: 0x%x", ["255"]); // "Wert: 0xff"

    // Binär-Ausgabe
    Fmt::printlnf("Bits: %b", ["42"]); // "Bits: 101010"
    return 0;
}
