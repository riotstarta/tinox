jwt

import tinox.core.jwt;

JWT-Token Erstellung und Verifikation mit HMAC-SHA256-Signatur und Ablaufprüfung.

Klassen

Jwt

MethodeSignaturBeschreibung
encodefn encode(payload: Map<String, JsonValue>, secret: String) -> StringPayload signieren und JWT erzeugen
decodefn decode(token: String, secret: String) -> Map<String, JsonValue>Token verifizieren und Payload zurückgeben
verifyfn verify(token: String, secret: String) -> BoolNur Signatur prüfen (kein Payload)
extractPayloadfn extractPayload(token: String) -> Map<String, JsonValue>Payload ohne Verifikation lesen
isExpiredfn isExpired(token: String) -> Boolexp-Claim gegen aktuelle Zeit prüfen

Beispiel

import tinox.core.jwt;
import tinox.core.json;

fn main() -> Int64
{
    let secret: String = "mein-geheimnis";
    let payload: Map<String, JsonValue> = Map::new();
    payload["sub"] = Json::parse("\"user42\"");
    payload["exp"] = Json::parse("9999999999");

    let token: String = Jwt::encode(payload, secret);
    println(token);

    let valid: Bool = Jwt::verify(token, secret);
    println(valid.toString()); // "true"

    let expired: Bool = Jwt::isExpired(token);
    println(expired.toString()); // "false"
    return 0;
}
