asm

import tinox.core.asm;

Low-Level Assembler-Modul zum Erzeugen von Bytecode. Stellt einen einfachen virtuellen Befehlssatz bereit.

Klassen

Assembler

Bytecode-Builder zum Emittieren von Opcodes und Labels.

MethodeSignaturBeschreibung
newfn new() -> AssemblerNeuen Assembler erstellen
emitfn emit(asm: Assembler, op: Int64) -> NothingEinzelnen Opcode hinzufügen
emitIntfn emitInt(asm: Assembler, value: Int64) -> Nothing64-Bit Integer als 8 Bytes emittieren
emitLabelfn emitLabel(asm: Assembler, name: String) -> NothingLabel an aktueller Position setzen
resolveLabelsfn resolveLabels(asm: Assembler) -> List<Int64>Bytecode mit aufgelösten Labels zurückgeben
toBytesfn toBytes(asm: Assembler) -> StringBytecode als String serialisieren

Ops

Opcode-Konstanten für den virtuellen Befehlssatz.

OpcodeWertBedeutung
Nop0Keine Operation
Halt1Programm beenden
Load2Wert laden
Store3Wert speichern
Push / Pop4 / 5Stack-Operationen
Add / Sub / Mul / Div6–9Arithmetik
Jmp / Jz / Jnz10–12Sprünge
Cmp13Vergleich
Call / Ret14 / 15Prozeduraufruf / Rückkehr

Beispiel

import tinox.core.asm;

fn main() -> Int64
{
    let asm: Assembler = Assembler::new();

    // Bytecode aufbauen: Push 10, Push 20, Add, Halt
    Assembler::emit(asm, Ops::Push());
    Assembler::emitInt(asm, 10);
    Assembler::emit(asm, Ops::Push());
    Assembler::emitInt(asm, 20);
    Assembler::emit(asm, Ops::Add());
    Assembler::emitLabel(asm, "end");
    Assembler::emit(asm, Ops::Halt());

    let bytecode: List<Int64> = Assembler::resolveLabels(asm);
    return 0;
}
