hpack

import tinox.core.hpack;

HPACK-Header-Kompression für HTTP/2 (RFC 7541). Implementiert Integer- und String-Kodierung, die vollständige statische Tabelle mit 61 Einträgen und eine dynamische Tabelle mit konfigurierbarer Maximalgröße. Wird intern von http2_server genutzt.

Dieses Modul ist ein Low-Level-Baustein für HTTP/2. In der Regel wird es nicht direkt verwendet — stattdessen nutzt man http2_server, das HPACK automatisch anwendet.

HpackDynTable

Dynamische HPACK-Tabelle (RFC 7541 §2.3.2). Neue Einträge werden vorne eingefügt; älteste Einträge werden verdrängt, wenn die Maximalgröße überschritten wird. Jeder Eintrag hat einen Overhead von 32 Bytes per Spezifikation.

Beispiel

import tinox.core.hpack;

fn main() -> Int32
{
    let encTable: HpackDynTable = HpackDynTable::new(4096);
    let decTable: HpackDynTable = HpackDynTable::new(4096);

    // Header-Liste kodieren
    let headers: List<HpackHeader> = [];
    headers.push(HpackHeader::new(":status", "200"));
    headers.push(HpackHeader::new("content-type", "application/json"));
    headers.push(HpackHeader::new("x-request-id", "abc-123"));

    let encoded: List<Int64> = Hpack::encode(headers, encTable);

    // Header-Block wieder dekodieren
    let decoded: List<HpackHeader> = Hpack::decode(encoded, decTable);

    let i: Int64 = 0;
    while i < decoded.len()
    {
        println(decoded[i].name + ": " + decoded[i].value);
        i = i + 1;
    }
    // Ausgabe:
    // :status: 200
    // content-type: application/json
    // x-request-id: abc-123

    return 0;
}
