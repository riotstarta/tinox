http2_server

import tinox.core.http2_server;

Vollständiger HTTP/2-Server (RFC 7540) mit binärem Framing, HPACK-Header-Kompression und Stream-Multiplexing. Die API ist identisch zu http_server — bestehende Route-Handler funktionieren unverändert.

Runtime-Voraussetzung: Der native Befehl httpServerReadRawBytes(fd, n) muss im Tinox-Runtime implementiert sein (liest genau n Bytes binär). Die übrigen Natives (httpServerCreate, httpServerAcceptConn, httpServerSendRaw, httpServerCloseConn) sind bereits vorhanden. HPACK-Kompression wird automatisch über das Modul hpack gehandhabt.

Verbindungsablauf

  1. Client sendet 24-Byte Connection Preface: "PRI * HTTP/2.0\r\n\r\nSM\r\n\r\n"
  2. Server sendet SETTINGS (Push disabled, max 128 Streams, Window 65535)
  3. Client sendet eigenes SETTINGS → Server antwortet mit SETTINGS ACK
  4. Client sendet HEADERS-Frame → optionale CONTINUATION-Frames → optionale DATA-Frames
  5. Bei END_HEADERS + END_STREAM: Handler wird aufgerufen
  6. Server sendet HEADERS + DATA als Antwort; leere Bodys erhalten END_STREAM im HEADERS-Frame
  7. Verbindung endet mit GOAWAY (Error Code 0)

Beispiel

import tinox.core.http2_server;

fn main() -> Int32
{
    let server: Http2Server = Http2Server::new(8080);

    server.get("/hello", fnc(ctx: HttpContext) -> Nothing {
        ctx.response.text("Hallo HTTP/2!");
    });

    server.get("/users/:id", fnc(ctx: HttpContext) -> Nothing {
        let id: String = ctx.request.getParam("id");
        ctx.response.status(200).json("{\"id\":" + id + "}");
    });

    server.post("/api/data", fnc(ctx: HttpContext) -> Nothing {
        let body: JsonValue = ctx.request.json();
        ctx.response.status(201).json("{\"ok\":true}");
    });

    // Auth-Middleware
    server.use(fnc(ctx: HttpContext) -> Bool {
        let token: String = ctx.request.getHeader("authorization");
        return token.startsWith("Bearer ");
    });

    server.listen(); // blockiert
    return 0;
}

Migration von http_server

// Vorher (HTTP/1.1)
import tinox.core.http_server;
let server: HttpServer = HttpServer::new(8080);

// Nachher (HTTP/2) — nur zwei Zeilen ändern
import tinox.core.http2_server;
let server: Http2Server = Http2Server::new(8080);

// Alle Route-Handler bleiben identisch
