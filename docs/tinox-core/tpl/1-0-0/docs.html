tpl

Generated by tinox doc

A minimal Mustache-like string template engine. Template::render substitutes {{key}} placeholders in a string with JSON-stringified values from a Map<String, JsonValue> in one pass; Template::compile/execute split that into a reusable parsed CompiledTemplate plus a separate execute step for repeated rendering.

Render placeholders

import tinox.core.tpl;
import tinox.core.json;

class Main
{
    fnc main() -> Int32
    {
        let data: Map<String, JsonValue> = Map::new();
        data["name"] = Json::parse("\"World\"");

        let output: String = Template::render("Hello, {{name}}!", data);
        println(output);

        return 0;
    }
}
