zip

Generated by tinox doc

Reads and writes STORED-only ZIP archives (no compression, text content) directly on disk. Zip::create/open give you a ZipArchive; addFile/extractFile/removeFile operate on named entries by content, not by handle.

Create and extract

import tinox.core.zip;

class Main
{
    fnc main() -> Int32
    {
        let archive: ZipArchive = Zip::create("/tmp/example.zip");
        Zip::addFile(archive, "hello.txt", "Hello, ZIP!");

        let reopened: ZipArchive = Zip::open("/tmp/example.zip");
        println(reopened.entries.len().toString());
        println(Zip::extractFile(reopened, "hello.txt"));

        Zip::close(reopened);
        return 0;
    }
}
