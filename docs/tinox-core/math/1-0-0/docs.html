math

Generated by tinox doc

Integer math helpers: constants (pi, e, tau), abs/min/max/square/pow/factorial for Int64, and a seeded linear-congruential pseudo-random generator. See mathf for the Float64 equivalents and mathx for number-theory functions (gcd, primes, combinatorics).
